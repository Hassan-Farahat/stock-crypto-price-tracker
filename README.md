# 📈 Stock & Crypto Price Tracker

A lightweight Streamlit web application to track live market prices, percentage changes, and historical performance for any stock or cryptocurrency ticker.

🚀 **[Live Demo](https://hassan-farahat-stock-price-tracker-app-uva15r.streamlit.app/)**

---

## ✨ Features

* **Ticker Lookup:** Search live data for any stock or cryptocurrency (e.g., `AAPL`, `TSLA`, `BTC-USD`).
* **Timeframe Selection:** Filter data across custom ranges (`1mo`, `3mo`, `6mo`, `1y`, `5y`, `max`).
* **KPI Dashboard:** View current price, dollar change, percentage change, and period high at a glance.
* **Interactive Visualizations:** Clean charts for closing price trends and daily trading volume.
* **Raw Data Explorer:** Inspect and review historical dataset records in an expandable view.

---

## 🛠️ Tech Stack

* **Python**
* **Streamlit** (UI Framework)
* **yfinance** (Financial Data API)
* **Pandas** (Data Manipulation)
